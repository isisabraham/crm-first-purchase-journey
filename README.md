# 🧭 Bagaggio First Purchase CRM Journey

This repository contains a visual flowchart of the **post-purchase CRM automation** for Bagaggio, a retail brand specializing in travel goods such as suitcases, backpacks, and accessories.

## 📂 File Included

- `Flowchart.jpg`: Visual flowchart exported from Miro, outlining the email and SMS/WhatsApp automation based on customer behavior after their first purchase.

## 🎯 Project Purpose

To design and document a segmented CRM journey for first-time buyers that:
- Encourages repeat purchases
- Introduces additional product categories
- Enhances brand experience and engagement
- Builds customer loyalty through timely, personalized communication

## ✨ Overview

Customers are segmented based on:
- The **type of product purchased** (e.g. suitcase vs. accessories)
- The **ticket value** of their order

Each branch includes **email marketing touchpoints** and optional **SMS/WhatsApp messages** delivered across a 45-day period post-purchase.

## 📦 Suitcase Buyer Journey

| Time        | Action                                                                 |
|-------------|------------------------------------------------------------------------|
| +1 Day      | Email 1 – Travel accessories offer (TSA locks, tags, etc.)            |
| +7 Days     | Email 2 – Travel tips + complementary product suggestions             |
| +14 Days    | Email 3 – Inspirational content (destinations + testimonials)         |
| +21 Days    | Split by ticket value:                                                 |
|             | - ≤ $499 → Email 3: Affordable add-on (carry-on or backpack)          |
|             | - > $499 → Email 4: Premium upsell (medium suitcase, deluxe kits)     |
| +30 Days    | SMS/WhatsApp – Limited-time reminder                                  |
| +45 Days    | Email 6 – Loyalty program + review request                            |

## 👜 Accessories Buyer Journey

| Time        | Action                                                                 |
|-------------|------------------------------------------------------------------------|
| +1 Day      | Email 1 – Brand & category introduction                                |
| +7 Days     | Email 2 – Style suggestions + cross-sell                               |
| +14 Days    | Email 3 – Everyday organization tips                                   |
| +21 Days    | Email 4 – Exclusive suitcase trial offer                               |
| +30 Days    | Email 5 – Smart add-ons reminder                                       |
| +45 Days    | Email 6 – Loyalty program + product review                             |

## 💬 Channels Used

- **Email Marketing**
- **SMS/WhatsApp** (for opted-in users)

## 🔧 Tools Suggested

- VTEX
- HubSpot
- Salesforce Marketing Cloud
- Dito CRM
- Any ESP that supports conditional logic and segmentation

## 📈 Optimization Tips

- Use **purchase tags** and **order value filters** for segmentation.
- Personalize content using **dynamic fields** (e.g. first name, product name).
- Track conversions with **UTM links**.
- Monitor open/click/redeem rates for retargeting flows.
